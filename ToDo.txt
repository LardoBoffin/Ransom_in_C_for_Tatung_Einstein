This binary file contains message numbers for rooms and links to other rooms in the format described below.
The first byte is number of messages. This cannot be zero.
Each message number is in two bytes, in the format of big-endian unsigned integer. 
So if the first number is three there will be three messages, or size bytes of numbers.
The next byte is the number of locations links. This is a single byte and can be zero.
Each location link is three bytes.
The first bytes is a single byte number which holds the verb number.
The next two bytes are a big-endian unsigned integer that holds the room number to link to.
So if the number of links is 2 the single byte number will be two and there will be six further bytes of numbers to make up the two links.

Please write a python script which extracts this data to a CSV file where the number of messages is a single value, followed by a comma, followed by the message numbers as numbers which can be greater than 256. Following this should be a number of locations links as a single number and then the locations as a single number of 1 to 256 for the verb and a number for the room that could be greater than 256. Remember that it is possible to have no location links in which case this number will be 0 and the next byte in the file will be the next record. The records are not terminated in any way and rely on the bytes determining how much data before the next record is decoded.
